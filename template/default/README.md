# __PROJECT_NAME__

A Filecoin Onchain Cloud starter generated by [`create-foc-app`](https://www.npmjs.com/package/create-foc-app).

## Start

```bash
cp .env.example .env.local
npm install
npm run foc:doctor
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), connect an injected wallet, and follow the four-stage flow:

1. connect a wallet on `__FOC_NETWORK__`;
2. calculate and execute Filecoin Pay funding/approval if required;
3. upload two copies and inspect the PieceCID/provider/dataset receipt;
4. retrieve by PieceCID and verify the exact bytes.

For Calibration, the wallet needs tFIL for gas and tUSDFC for storage. See the [Filecoin Onchain Cloud quick start](https://docs.filecoin.cloud/getting-started/).

## Commands

```bash
npm run dev             # local Next.js server
npm run foc:doctor      # offline readiness and secret-safety checks
npm run lint            # ESLint
npm run typecheck       # TypeScript
npm test                # offline unit tests
npm run build           # production build
npm run check           # all offline checks
npm run foc:smoke-test  # funded, live Calibration upload/retrieval
```

## Live smoke test

The smoke test is deliberately opt-in and Calibration-only:

```bash
cp .env.example .env.local
# Add FOC_SMOKE_PRIVATE_KEY to .env.local (never NEXT_PUBLIC_*)
npm run foc:smoke-test
```

It prepares the account, uploads two copies, downloads by PieceCID, compares the bytes, and prints a machine-readable `FOC_SMOKE_RESULT=...` receipt.

## Architecture

- `app/page.tsx` owns UI state and the four-step demo.
- `lib/foc/adapter.ts` is the only browser module coupled to Synapse SDK.
- `lib/foc/types.ts` defines JSON-safe application receipts.
- `lib/foc/verify.ts` contains pure content verification helpers.
- `scripts/foc-doctor.mjs` is read-only and wallet-free.
- `scripts/foc-smoke-test.mjs` is the only private-key path and runs in Node.js.

## Security

- Never put private keys in `NEXT_PUBLIC_*` variables.
- Never move `FOC_SMOKE_PRIVATE_KEY` into client code.
- Keep `.env.local` out of Git.
- Treat Mainnet transactions as real-value operations.
- Review upload content before committing it to persistent decentralized storage.
